Machine Learning Bootcamp

Master AI/ML fundamentals in just 1 week | Live sessions with an IIT Hyderabad researcher

Why This Bootcamp?

Hi, I’m Divya Rajparia, and I work on machine learning research at IIT Hyderabad and the University of Southern California.

This intensive 1-week bootcamp will take you from the fundamentals to building your own machine learning projects, with a strong focus on hands-on, practical learning.

Whether you're a complete beginner or already have some coding experience, this bootcamp is designed to help you build a strong foundation and apply ML concepts with confidence.

What You'll Learn

Week Overview

Day 1-2: Python & ML Foundations

  • Python programming essentials for ML
  • NumPy and Pandas for data manipulation
  • Introduction to Machine Learning concepts
  • Setting up your ML development environment

Day 3-4: Core ML Algorithms

  • Linear Regression and Classification
  • Decision Trees and Random Forests
  • Support Vector Machines
  • Model evaluation and validation

Day 5-6: Deep Learning Basics

  • Neural Networks fundamentals
  • Introduction to PyTorch/TensorFlow
  • Building your first neural network
  • Image classification with CNNs

Day 7: Real-World Project

  • Work on a complete ML project from scratch
  • Deploy your model
  • Best practices for ML development
  • Next steps in your ML journey

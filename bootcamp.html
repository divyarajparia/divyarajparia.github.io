Machine Learning Bootcamp

Master AI/ML fundamentals in just 1 week | Live sessions with an IIT Hyderabad researcher

Why This Bootcamp?

Hi, I’m Divya Rajparia, and I work on machine learning research at IIT Hyderabad and the University of Southern California.

This intensive 1-week bootcamp will take you from the fundamentals to building your own machine learning projects, with a strong focus on hands-on, practical learning.

Whether you're a complete beginner or already have some coding experience, this bootcamp is designed to help you build a strong foundation and apply ML concepts with confidence.

What You'll Learn

5-Day Bootcamp Overview

Day 1: Smart Programming with AI Assistance

  • How developers use AI as a coding tool
  • Quick revision of core programming concepts through mini-projects
  • Building logic-based programs with AI support
  • Understanding and modifying AI-generated code

Day 2: Working with Data & Patterns

  • How data is represented in programs
  • Cleaning and organizing real-world data
  • Visualizing data using simple graphs
  • Finding patterns through basic data analysis

Day 3: Introduction to Machine Learning

  • What Machine Learning really is (with real-life examples)
  • How machines learn from data
  • Understanding training vs testing
  • Building your first simple prediction model

Day 4: Improving Machine Learning Models

  • Understanding prediction errors
  • How accuracy is measured in simple terms
  • Improving results using better data
  • Fine-tuning and testing ML models

Day 5: Regression-Based Mini Project & Showcase

  • Understanding regression through real-life use cases
  • Building a complete regression-based prediction project
  • Testing the model with real inputs
  • Final showcase, and next learning steps

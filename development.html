Real-Time Object Detection & Tracking

A collection of computer vision applications built with YOLOv8 and SORT tracker, demonstrating real-world object detection and tracking across different scenarios. These projects showcase end-to-end implementation of deep learning models for practical use cases.

Technologies: YOLOv8, SORT (Kalman Filter + Hungarian Algorithm), Python, OpenCV

Car Counter

People Counter

Bidirectional foot traffic tracking and counting with separate detection lines for entry and exit monitoring

Safety equipment detection system identifying helmets, vests, gloves, boots, and goggles for construction site compliance

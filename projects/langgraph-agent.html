Project

Multi-Source Web Research Agent

Overview

A stateful multi-source research agent built in LangGraph that runs parallel web searches across Google, Bing, and Reddit simultaneously. Given a research query, it asynchronously scrapes results via BrightData SERP, ranks URLs using a zero-shot LLM call, and synthesizes a structured report from the top sources using GPT-4o. Designed with Pydantic-structured outputs throughout for type safety and reliable parsing.

Key Features
  • Parallel multi-source search across Google, Bing, and Reddit in a single LangGraph workflow
  • BrightData SERP integration for async scraping with rate-limit handling
  • Zero-shot LLM-based URL ranking to filter low-quality sources before synthesis
  • Pydantic-structured outputs at every node for reliable, type-safe data flow
  • Modular synthesis pipeline using GPT-4o to combine and reconcile results from multiple sources
  • Stateful graph design enabling easy inspection of intermediate results and replay
Technologies

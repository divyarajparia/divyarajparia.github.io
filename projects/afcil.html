DES: A Smarter Way to Grow ML Models Over Time

Overview

A new continual learning setup called AFCIL (Assumption-Free Class-Incremental Learning) that removes the unrealistic assumptions most existing methods rely on — no balanced data, no stored old samples, and full support for pre-trained models like CLIP. We introduced a two-stage training strategy called Dynamic Expert Saturation (DES): the model first trains on head (frequent) classes, then incrementally saturates to tail (rare) classes using dynamically added lightweight MLP expert adapters. This naturally handles class imbalance and prevents catastrophic forgetting without replay buffers.

Key Features
  • No stored data or replay buffers — works under strict privacy and memory constraints
  • Handles long-tailed class distributions natively via two-stage expert saturation
  • Plug-and-play with pre-trained vision-language backbones (CLIP)
  • State-of-the-art on CIFAR-100-LT and ImageNet-LT, outperforming DualPrompt, CODA, and MoE-Adapter by up to 6% top-1 accuracy
  • Lightweight MLP adapters keep compute overhead minimal

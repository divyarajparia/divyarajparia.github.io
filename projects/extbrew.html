ExtBrew — AI-Native Chrome Extension Scaffolder

Overview

A web application that scaffolds complete Chrome Manifest V3 extensions from natural-language prompts using Claude Sonnet 4.6. The user describes what they want their extension to do, and ExtBrew generates a fully structured multi-file project — visible in a Monaco editor — through a real-time streaming tool-use loop. Designed with a bring-your-own-key model for zero server-side API cost.

Key Features
  • Natural-language to Chrome extension scaffolding using Claude Sonnet 4.6 with streaming
  • Token streaming via Anthropic Server-Sent Events on a Next.js Edge route using TransformStream
  • Tool-use loop where Claude invokes create_file, edit_file, and delete_file to incrementally build projects
  • Monaco editor integration showing the full multi-file project structure in real time
  • Bring-your-own-key flow with localStorage persistence and an SSR-safe hydration hook to prevent React mismatches
  • Generates Manifest V3-compliant extensions ready to load into Chrome
Technologies
Next.js TypeScript Claude API (Sonnet 4.6) Anthropic SDK Monaco Editor Edge Runtime Chrome Manifest V3 SSE / TransformStream
